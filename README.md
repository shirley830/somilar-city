Solmar — Sun, Sand & Sirens: an original open-world crime game set in the sun-soaked coastal city of Solmar. Milo Kade, new in town, runs jobs for fixer Vera Solano — stealing cars, outrunning the Solmar PD, and working six story missions across a living city of traffic, pedestrians, and police.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests at runtime — the game is plain static files under `game/`.

## How to play

- WASD move / drive · Mouse aim, click shoot · E enter car / interact · F punch · R reload · Shift run · N next job · P pause · M mute
- Steal cars (not police cars), take jobs from Vera, dodge the wanted level — and find all 10 hidden packages across the city.
- Progress saves in the browser (localStorage) when you finish a job.
